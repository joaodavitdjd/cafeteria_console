# Cafeteria Console

Sistema de console em Java para controlar os produtos de uma cafeteria.
Projeto de estudo de Java e POO.

## Funcionalidades
- Cadastrar produto (nome, preço, estoque e categoria)
- Listar produtos
- Adicionar e remover estoque

## Como rodar
Abra o projeto no IntelliJ IDEA e execute a classe `Main`.
